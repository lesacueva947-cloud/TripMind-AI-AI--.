# План разработки TripMind AI

## Цель
Создать локальный MVP-сервис для генерации маршрута путешествия по дням с учётом бюджета, интересов, состава путешественников и темпа поездки.

## Этапы

1. Подготовить базовую структуру проекта и проверить стартовые сценарии.
2. Реализовать генератор маршрута и сравнение сценариев.
3. Сделать локальный интерфейс для ввода параметров и отображения результата.
4. Добавить поведенческие проверки для погоды и AI-чат ответа.
5. Прогонять автоматические тесты и подготовить финальный коммит.

## Критерии приёмки

- В приложении есть форма ввода параметров поездки.
- Генерируется маршрут по дням с адаптацией под погоду.
- Поддерживаются сценарии `econom`, `comfort`, `premium`.
- Есть визуальная карта/сводка маршрута и блок с AI-советами.
- Проект успешно запускается и проходит тесты.
