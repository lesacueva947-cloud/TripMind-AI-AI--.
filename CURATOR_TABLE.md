## Краткое описание проекта
TripMind AI — сервис для генерации персонального маршрута путешествия по дням с учётом бюджета, интересов, состава участников и темпа поездки.

## Основные критерии проверки
- Пользователь может ввести параметры поездки и получить план по дням
- Поддерживаются сценарии: эконом, комфорт, премиум
- Маршрут учитывает бюджет, интересы, состав группы и темп поездки
- Есть маршрутная сводка и AI-ответ по логике маршрута
- MVP запускается локально и покрыт базовыми тестами

## Итог
После первого коммита и реализации минимальной фичи проект будет готов для регулярной проверки в репозитории и дальнейшего уточнения дедлайна по ДЗ.
