# TripMind AI

- Outcome: сервис для генерации персонального маршрута путешествия по дням с учётом бюджета, интересов, состава путешественников и темпа поездки.
- User: частные путешественники, пары и семьи, планирующие поездку без длительного ручного подбора маршрута.
- Why now: пользователи хотят быстро сравнить варианты поездки и получить адаптированный план без переплаты и без ручного сбора информации по каждому дню.
- Success: пользователь вводит город, даты, бюджет, интересы, состав группы и темп; получает готовый маршрут на несколько дней, варианты сценариев, карту-сводку, адаптацию под погоду и быстрый AI-чат-ответ по плану.
- Constraint: MVP реализуется локально в рамках одного проекта без внешних платных API; основной функционал должен работать без сторонних сервисов.
- Out of scope: онлайн-бронирование, реальные платёжные операции, интеграция с картами и погодой в продакшн-режиме, backend с базой данных.

## Критерии приёмки

- Пользователь может ввести параметры поездки и получить план по дням.
- Поддерживаются три сценария: эконом, комфорт и премиум.
- План учитывает бюджет, интересы и состав группы.
- Присутствует карта/маршрутная сводка и AI-чат-стиль ответа.
- Есть адаптация маршрута при изменении погоды.
- Проект запускается локально и покрыт базовыми автоматическими тестами.
