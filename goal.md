# TripMind AI

- Outcome: сервис для генерации персонального маршрута путешествия по дням с учётом бюджета, интересов, состава путешественников и темпа поездки.
- User: частные путешественники, пары и семьи, которые хотят быстро получить готовый маршрут без ручного подбора по каждому дню.
- Why now: пользователи хотят сокращать время планирования, сравнивать несколько сценариев поездки и избегать переплаты при сохранении комфортного уровня сервиса.
- Success: пользователь вводит город, даты, бюджет, интересы, состав группы и темп; получает готовый маршрут на несколько дней, сценарии эконом/комфорт/премиум, карту-сводку, адаптацию под погодные условия и краткий AI-ответ по логике маршрута.
- Constraint: MVP реализуется локально в рамках одного проекта без внешних платных API; основной функционал должен работать без сторонних сервисов.
- Out of scope: онлайн-бронирование, реальные платёжные операции, production-интеграции с картами и погодой, полноценный backend с базой данных.

## Критерии приёмки

- Пользователь может ввести параметры поездки и получить план по дням.
- Поддерживаются три сценария: эконом, комфорт и премиум.
- План учитывает бюджет, интересы, состав группы и темп поездки.
- Присутствует карта/маршрутная сводка и AI-чат-стиль ответа.
- Есть адаптация маршрута при изменении погоды.
- Проект запускается локально и покрыт базовыми автоматическими тестами.
